Pass rate statistics of engineering colleges affiliated to APJ Abdul Kalam Technological University (KTU), Kerala.

All data displayed is scraped from public sources such as the results published on the official KTU website. This project is not affiliated with KTU and the data is not guaranteed to be accurate and is provided as-is.

### Run Locally

```bash
git clone https://github.com/chayotic/ktu-stats.git
cd ktu-stats
npm install
npm run dev
```
